# AML Transaction Monitoring System Implementation

**Portfolio project by Blessing Adeniyi, PMP**

> This is a simulated project built for my professional portfolio. Prairie Trust Bank is a fictional organization, and all names, figures and data are invented. The documents reflect how I plan, run and close a technology project in an Anti Money Laundering (AML) compliance setting.

## Project overview

Prairie Trust Bank, a mid sized Canadian bank, relies on manual spreadsheet reviews to spot suspicious transactions. The process is slow, inconsistent and hard to audit. This project replaces it with an automated transaction monitoring system that flags unusual activity, routes alerts to analysts, and supports timely reporting to FINTRAC.

## My role

Project Manager, responsible for initiation through closing: business case, planning, stakeholder management, Agile delivery, risk and change control, user acceptance testing, and go live.
